# SIH 26177 Website

Full presentation website plus embedded browser simulator.

## Structure
- `index.html` — public landing website
- `style.css` — website styling
- `simulator/` — live browser simulator
- `README.md` — deployment notes

## GitHub Pages
Upload the entire folder contents to a GitHub repository with `index.html` in the repository root. Enable Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The site is static and needs no server or Python runtime.
